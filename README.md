# STM_molecula_inventada
Archivos sobre la visualización mediante simulación de STM de mi molécula inventada.

Hay varios voltajes positivos y negativos. Esto se debe a que inicialmente usé 3V y -3V, unos voltajes que prácticamente solo mostraban estados de los átomos electronegativos (3V) y electropositivos (-3V). Los voltajes de 5V y -4V muestran más estados y permite interpretar mejor la estructura.
